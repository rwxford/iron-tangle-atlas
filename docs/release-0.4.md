# Reader 0.4.0 - interpretive 3D noodles

This release adds an optional 3D reconstruction without replacing the evidence-labelled 2D map.

- Three rotatable double-sided noodles form an intentionally interpretive emblem silhouette.
- Each noodle carries a different colored line on each opposing face.
- Top, oblique and side camera presets make the two-sided structure legible.
- Mouse drag, single-finger drag, pinch zoom, wheel zoom and keyboard controls are supported.
- The view is persistently labelled `INTERPRETIVE / GEOMETRY UNCONFIRMED`.

The model demonstrates the book's structural concept. It does not claim that the chosen curves reproduce the Syndicate logo, Katia's drawings, station placement, line assignment, scale or crossing geometry. Those remain primary-source research tasks.
